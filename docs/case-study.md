# 사례: 내수합판 12mm 설치 일위대가

지붕바탕에 내수합판을 추가하고 싶다는 실무 요청에서 출발했다. 사용자가 지정한 조건은 **두께 12mm**, 지붕 전체 적용, 기존 하지틀 설치비와 별도인 추가 공사였다. 재료 단가는 자료에서 조사하고 없으면 추정해도 된다는 요청이 있었다.

여기서는 후속 요청인 “새 외부가격 연결로 합판만 별도 일위대가 산출”의 결과를 다룬다. 2026-10-06에 계산한 **1㎡당 직접공사비 추정값은 31,092원**이었다. 현재가격이나 승인된 공사단가로 제시하는 값은 아니다.

## 먼저 구분한 조건

| 구분 | 내용 |
|---|---|
| 사용자 지정 | 두께 12mm, 기존 하지틀과 별도인 합판 추가 설치 |
| 산출 기준 | 합판 공급·절단·고정 설치 1㎡ |
| 조사로 확인한 값 | 합판 공급 참고가격과 단위·공표일·세금·인도조건, 노임 판본, 유사 작업 품셈 |
| 작성 시 선택한 가정 | 1급·1220×2440mm, 손실 3%, 고정재 3%, 벽체 작업조의 지붕 준용, 별도 노무가산 0% |
| 포함하지 않은 범위 | 기존 하지틀·징크·방수시트, 제경비·이윤·부가세 |

사용자가 단가 추정을 허용했다고 해서 가정값을 사용자가 지시한 가격으로 기록하지 않았다. 사용자 조건, 공표 자료, 작성자 가정을 나누어 저장했다.

## 1. 합판 공급가격 확인

2026-10-06 조달청 시설공통자재 API에서 내수합판 식별번호 **20142458**을 조회했다. 응답의 6개 공표판본 중 해당 조회 시 최신인 2026-10-01 공표값을 선택했다.

| 항목 | 확인 내용 |
|---|---|
| 품명·규격 | 내수합판, 1급, 12×1220×2440mm |
| API 원문 단위 | ㎡ |
| 공급 참고가격 | 11,554원/㎡ |
| 공표일 / 조회일 | 2026-10-01 / 2026-10-06 |
| 세금 | 부가가치세 별도 |
| 인도조건 | 현장도착도 |
| 미기재 | 지역, 추가 적용범위, 유효기간, 삭제 여부 |

독립 시설자재 파일의 같은 규격·가격과도 대조했다. 가격의 출처는 [조달청 시설자재 가격정보 API](https://www.data.go.kr/data/15129415/openapi.do)이며, 공개 저장소에는 원시 응답과 담당자·연락처 필드를 재배포하지 않는다.

이 상품은 판 크기가 적혀 있어도 가격 단위는 ‘매’가 아닌 ‘㎡’였다. 단위 확인 없이 판 면적으로 한 번 더 나누면 가격이 잘못된다. 또한 공급 참고가격 하나에는 지붕 설치 노무비가 포함되어 있지 않으므로 설치 일위대가를 별도로 구성했다.

## 2. 설치 노무와 경비의 근거·가정

확인한 표준품셈의 벽체합판 설치 항목에는 건축목공 2인, 보통인부 1인, 작업량 40㎡/일과 공구·경장비 조건이 있었다. 이 사례에서는 지붕 전용 품을 확정하지 못해 **벽체 작업조를 유사 작업으로 준용한 추정**이라고 표시했다.

노임은 2026-09-01 판본의 건축목공 282,990원/인·일, 보통인부 172,698원/인·일을 적용했다. 해당 판본 확인 기록은 2026-10-06 기준이다. 공표 기본급을 사용했으며 제수당·상여금·퇴직급여·현장별 할증을 별도로 확정한 값은 아니다.

판재 손실 3%와 고정재 3%는 공식 고정요율로 확인한 값이 아니라 작성자 추정이다. 지붕 경사, 작업 높이, 양중, 안전시설, 기존 바탕 상태가 달라지면 생산성과 비용을 다시 검토해야 한다.

## 3. 자원별 계산

계산은 자원별 금액의 원 미만을 절사한 뒤 합산했다. `TRUNC`는 이 사례의 양수 금액에서 원 미만을 버린다는 뜻이다.

| 자원 | 산식 | 원/㎡ |
|---|---|---:|
| 손실 포함 합판 | TRUNC(11,554 × 1.03) | 11,900 |
| 고정재 추정 | TRUNC(11,900 × 0.03) | 357 |
| 건축목공 | TRUNC(282,990 × 2 ÷ 40) | 14,149 |
| 보통인부 | TRUNC(172,698 × 1 ÷ 40) | 4,317 |
| 공구·경장비 | TRUNC((14,149 + 4,317) × 0.02) | 369 |

| 비목 | 원/㎡ |
|---|---:|
| 재료비 | 12,257 |
| 노무비 | 18,466 |
| 경비 | 369 |
| 직접공사비 추정 합계 | **31,092** |

이 합계에는 제경비·이윤·부가세가 포함되지 않는다. 전체 면적을 곱한 금액과 연차별 내역서 반영은 별도 작업이다. 이 일위대가 산출 작업에서 기존 내역서 전체를 편집하지 않았다.

## 4. 계산 결과 검증

과거 실행 기록에서는 독립 Decimal 계산과 저장 Excel 값 16개, 실제 Microsoft Excel 재계산 결과가 일치했다. 별도 사본에서 합판 공급가격을 1,000원 올렸을 때 총액이 **32,152원/㎡**으로 바뀌고, 입력을 원복한 뒤 원래 결과로 돌아오는지도 확인했다.

공급가격 1,000원 증가가 총액 1,000원 증가로 끝나지 않는 이유는 합판 손실과 고정재가 공급가에 함께 연결되어 있기 때문이다. 이 변화 검사는 계산값을 고정 입력해 둔 경우와 실제 수식 연동을 구별하는 데 도움이 된다.

저장 수식 오류 검사와 두 시트의 시각 검토도 통과한 기록이 있다. 원본 파일과 기준 DB의 전후 SHA256은 동일했다. 공개 저장소를 작성하면서 이 실제 API·Excel 검사를 새로 실행한 것으로 보고하지는 않는다.

## 5. 실패와 피드백이 드러낸 점

이 사례에 앞선 내역서 추가 과정에서는 사용자가 “다른 페이지에 반영되지 않았다”고 피드백했다. 행 하나의 금액 계산이 맞아도 다른 시트, 총괄·연차, 숨김 행과 원가계산서까지 연결되었는지는 별도 확인이 필요하다는 문제였다.

이 문제를 해결했다고 단정하는 대신 검증 단위를 나눴다. 이 문서의 별도 일위대가는 1㎡의 구성비와 입력 변화가 검증된 결과이고, 기존 내역서 전체 연결 수정 완료를 증명하는 결과는 아니다. 이후 문서 반영 작업에는 대상 연차, 추가 행, 연결 소계와 상위 집계, 원본의 기존 오류를 구분한 검증이 필요하다.

외부가격 경로를 적용하면서 기존 문서에 저장된 관찰가격을 신규가격으로 자동 사용하던 위험도 줄였다. 다만 외부 공급가격이 확보되어도 지붕 작업의 생산성과 현장 조건이 자동 확정되는 것은 아니다. **데이터 조회 성공, 산술 검증, 현장 적용 승인**을 구별하는 것이 이 사례의 핵심 설계 판단이다.

## 공개 데모와의 관계

실제 현장명·원본 파일·DB·API 응답은 제외했다. 공개 데모는 합성 fixture로 계산과 오류 처리 구조를 보여주며, 이 문서의 2026-10-06 결과는 날짜와 가정을 보존한 과거 사례 설명이다. 2026-10-25 또는 이후의 견적에는 새 가격 조회와 현장 조건 확인이 필요하다.
